# VGHelper

VGHelper is a small Ruby helper library for creating interactive
[Vega-Lite](https://vega.github.io/vega-lite/) charts from
`Rover::DataFrame`.

It provides convenient helpers for time-series and nominal x-axis charts,
with support for multiple categories, secondary y-axes, reference lines,
interactive range controls, brush statistics, and offline HTML output.

One of the main goals of VGHelper is to make Vega-Lite charts usable
even in **offline or proxy-restricted environments**.

VGHelper bundles the JavaScript runtimes required by Vega, Vega-Lite,
and Vega-Embed, so HTML generated by VGHelper does not need to load
these libraries from an external CDN.

## Features

- Time-series charts (`draw_xdate`)
- Nominal / categorical x-axis charts (`draw_xnominal`)
- Multiple series and multiple category columns
- Line charts with optional point markers
- Secondary y-axis with bar charts
- Stacked bars using a secondary category
- Horizontal reference lines
- Vertical reference lines
- Configurable colors for reference lines
- Interactive x-axis range controls
- Interactive y-axis range controls
- Category visibility checkboxes
- Brush selection
- Statistics for the selected / displayed range
  - count
  - mean
  - standard deviation
  - maximum
  - minimum
- Statistics based on total stacked-bar height for the secondary axis
- Daily and exact-time modes for temporal data
- Reversible left/right y-axis orientation
- Self-contained offline HTML output
- Export the current chart as PNG (2x resolution) or SVG
- No CDN access required for generated HTML

## Installation

Add this line to your application's Gemfile:

```ruby
gem "vg_helper"
```

and run:

```sh
bundle install
```

```sh
gem install vg_helper
```

```ruby
require "vg_helper"
```

## Quick Start

```ruby
require "vg_helper"
require "rover"

df = Rover::DataFrame.new(
  {
    "datetime" => [
      "2026-01-01 10:00:00",
      "2026-01-02 10:00:00",
      "2026-01-03 10:00:00",
      "2026-01-04 10:00:00"
    ],
    "category" => [
      "A", "A", "A", "A"
    ],
    "value" => [
      10, 15, 12, 18
    ]
  }
)

chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "value",
  "category"
)
```

### Jupyter Notebook / IRuby

In Jupyter Notebook with IRuby, place the chart object at the end of
the cell to display it directly:

```ruby
chart
```

A complete cell can simply end with:

```ruby
chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "value",
  "category"
)

chart
```

The same applies to charts created with `draw_xnominal`.

### Offline HTML output

To write the chart to an HTML file instead, use `write_htmls`:

```ruby
VGHelper.write_htmls(chart, "chart.html")
```

`write_htmls` uses the bundled `vega.min.js`, `vega-lite.min.js`, and
`vega-embed.min.js` files. The generated HTML does not load these
libraries from a CDN and can be viewed without a network connection.

Open `chart.html` in a browser to view the interactive chart.

# `draw_xdate`

`draw_xdate` creates a chart with a temporal x-axis.

```ruby
VGHelper.draw_xdate(
  df,
  x_col,
  y_col,
  category_col,
  ...
)
```

Basic example:

```ruby
chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "temperature",
  "station"
)
```

The fourth argument specifies the column used to separate the data
into series.

Category values and an explicit `categories:` list are normalized to
strings internally, including numeric categories. The input DataFrames
are not modified. This applies to both chart helpers and both axes.

## NaN warnings

Before preparing either DataFrame, VGHelper warns on standard error with
the DataFrame name (`df` or `df2`), column name, and number of NaN values.
No rows are dropped and the original DataFrame remains unchanged.
Since JSON cannot represent NaN, those cells become `null` only in the
generated chart data. Vega-Lite handles them as missing values. This is
not imputation: VGHelper does not replace missing measurements with zero.
An all-missing measure uses a fallback axis range of `[0, 1]`; a date
chart with no valid x values raises `ArgumentError` after warning.

---

## Multiple category columns

An array of columns can be supplied as `category_col`.

```ruby
chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "temperature",
  ["pref", "city"]
)
```

VGHelper combines the values internally and treats each combination
as an independent series.

---

## Time modes

`draw_xdate` supports two time modes.

### Daily mode

```ruby
time_mode: :day
```

Dates are normalized to the beginning of each calendar day.

This is useful when the time of day is irrelevant and the x-axis
should represent daily observations.

```ruby
chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "value",
  "category",
  time_mode: :day
)
```

### Exact-time mode

```ruby
time_mode: :exact
```

The time of day is preserved.

```ruby
chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "value",
  "category",
  time_mode: :exact
)
```

Use this for hourly, minute-level, or other intraday data.

# `draw_xnominal`

`draw_xnominal` creates a chart whose x-axis consists of discrete
ordered values.

For example:

```ruby
df = Rover::DataFrame.new(
  {
    "step" => [
      "STEP_001",
      "STEP_002",
      "STEP_003",
      "STEP_004"
    ],
    "value" => [
      10, 13, 18, 16
    ],
    "category" => [
      "A", "A", "A", "A"
    ]
  }
)

chart = VGHelper.draw_xnominal(
  df,
  "step",
  "value",
  "category"
)
```

The original order of x values is preserved.

This makes `draw_xnominal` useful for data such as:

```text
STEP_001
STEP_002
STEP_003
...
```

where the x values are categories but their sequence is meaningful.

---

## Limiting the initial x range

For large nominal datasets:

```ruby
initialxpoints: 100
```

controls the number of x positions initially displayed.

For example:

```ruby
chart = VGHelper.draw_xnominal(
  df,
  "step",
  "value",
  "category",
  initialxpoints: 100
)
```

# Interactive controls

## X-axis controls

The x-axis range controls can be enabled or disabled.

```ruby
xslide: true
```

or:

```ruby
xslide: false
```

For `draw_xdate`, the controls modify the temporal range.

For `draw_xnominal`, they modify the range of displayed x positions.

---

## Y-axis controls

Y-axis controls can be enabled with:

```ruby
yslide: true
```

and disabled with:

```ruby
yslide: false
```

The control type can also be selected:

```ruby
yrangechanger: "number"
```

or:

```ruby
yrangechanger: "range"
```

Explicit y ranges can be supplied where appropriate:

```ruby
miny: 0,
maxy: 100
```

---

## Category checkboxes

Series visibility can be controlled interactively.

```ruby
category_check: true
```

This adds a checkbox for each category.

To hide these controls:

```ruby
category_check: false
```

---

# Brush selection and statistics

Both chart helpers support interactive x-axis brush selection.

Drag across part of the chart to select a range.

VGHelper displays statistics for the selected data:

```text
n
avg
std
max
min
```

For example:

```text
temperature  n: 32  avg: 21.45  std: 2.18  max: 25.60  min: 17.90
```

When no smaller brush range is selected, the statistics correspond
to the currently displayed range.

Category visibility settings are also reflected in the statistics.

# Secondary y-axis

A second `Rover::DataFrame` can be displayed as bars using a
secondary y-axis.

```ruby
chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "temperature",
  "station",

  df2: volume_df,
  x2_col: "datetime",
  y2_col: "volume"
)
```

This produces a main chart together with bars using an independent
y scale.

## Secondary marks and axis limits

Use `markkind2:` to choose a secondary mark. The default remains bars;
`:line`, `:line_dot`, `:point` (an alias for `:small_dot`), `:large_dot`,
and custom mark hashes are also supported.

```ruby
chart = VGHelper.draw_xdate(
  df, "datetime", "temperature", "station",
  df2: pressure_df, x2_col: "datetime", y2_col: "pressure",
  markkind2: :line_dot,
  miny2: 900, maxy2: 1100
)
```

`miny2:` and `maxy2:` set the secondary scale's domain. An omitted bound
is inferred from its data. Bar bounds include zero and account for
positive and negative stacked heights; line and point bounds use
individual observations. Explicit secondary limits are not expanded
by scale rounding or zero inclusion. These options also work with
`draw_xnominal` and `reverse_orient: true`.

Secondary bar statistics use one stacked total per x position. Secondary
line and point statistics use individual observations.

---

## Stacked secondary-axis bars

A category can also be assigned to the secondary data.

```ruby
chart = VGHelper.draw_xdate(
  df,
  "datetime",
  "temperature",
  "station",

  df2: volume_df,
  x2_col: "datetime",
  y2_col: "volume",
  y2_category_col: "product"
)
```

Rows sharing the same x position are displayed as stacked bars.

For statistical calculations, VGHelper first calculates the total
height of each stacked bar.

For example, if one x position contains:

```text
Product A : 10
Product B : 15
Product C : 5
```

it is treated as one observation:

```text
30
```

The mean, standard deviation, maximum, minimum, and count displayed
for the secondary axis are then calculated from these stacked totals,
rather than from the individual bar segments.

---

# Axis orientation

By default, the main y-axis is displayed on the left and the
secondary y-axis on the right.

The orientation can be reversed:

```ruby
reverse_orient: true
```

This places the main axis on the right and the secondary axis
on the left.

---

# Horizontal reference lines

Horizontal reference lines can be added with `horizontallines`.

```ruby
horizontallines: [
  [20, "Target"],
  [30, "Upper Limit"]
]
```

Colors can be specified separately:

```ruby
horizontalcolors: [
  "#0000ff",
  "#ff0000"
]
```

Reference lines are useful for targets, limits, thresholds,
specifications, and other fixed values.

---

# Vertical reference lines

Vertical reference lines can also be added.

For a date chart:

```ruby
verticallines: [
  ["2026-01-10", "Close"],
  ["2026-01-20", "Restart"]
]
```

For a nominal chart:

```ruby
verticallines: [
  ["STEP_020", "Event A"],
  ["STEP_050", "Event B"]
]
```

Colors can be specified with:

```ruby
verticalcolors: [
  "#0000ff",
  "#ff0000"
]
```

Vertical lines can be used to indicate important x positions.

---

# Custom marks

The Vega-Lite mark definition can be customized with `markkind`.

For example:

```ruby
markkind: {
  type: "line",
  point: {
    filled: true,
    size: 40
  },
  tooltip: true
}
```

This allows VGHelper to expose Vega-Lite's mark configuration while
providing convenient defaults.

## Stacked bars on the main axis

```ruby
chart = VGHelper.draw_xnominal(
  df, "step", "value", "category",
  markkind: :bar
)
```

Main-axis bars stack by category at each x position by default. The
automatic y range includes the full positive and negative stack heights,
and statistics use each x position's total as one observation. Category
visibility and brush selection are applied before calculating totals.

Use `stack: false` for overlapping, unstacked main-axis bars. Lines and
points remain unstacked and use individual observations for statistics.

# Offline HTML output

VGHelper is designed to work without access to external CDNs.

The gem bundles local copies of:

```text
vega.min.js
vega-lite.min.js
vega-embed.min.js
```

`write_htmls` embeds these JavaScript files directly into the output
HTML.

```ruby
VGHelper.write_htmls(
  chart,
  "chart.html"
)
```

The resulting file can therefore be opened without accessing
jsDelivr, unpkg, or another CDN.

This can be particularly useful in:

- corporate proxy environments
- restricted networks
- isolated analysis environments
- offline machines

Multiple charts can also be written to the same HTML file:

```ruby
VGHelper.write_htmls(
  [chart1, chart2, chart3],
  "charts.html"
)
```

## Get the HTML string without saving a file

`VGHelper.to_html` returns the same standalone HTML document, with the
bundled runtimes, for one chart or an array of charts:

```ruby
html = VGHelper.to_html([chart1, chart2])
html = html.sub("</head>", "<style>body { margin: 2rem; }</style></head>")
File.write("custom-charts.html", html, encoding: "utf-8")
```

You can insert your own CSS or JavaScript before serving or saving the
string. `write_htmls(charts, out)` now delegates to `to_html(charts)` and
writes its result as UTF-8. This module method returns a full document;
the `vega` chart object's existing `chart.to_html` returns its embed
fragment.

# Saving charts as images

Charts created by `draw_xdate` and `draw_xnominal` have an actions menu
(the three dots at the top right). Select **Save as PNG** or **Save as SVG**
to download the chart currently displayed.

- PNG exports use 2x resolution for clearer text and lines.
- SVG exports retain vector graphics for resizing.
- Changes to the axis ranges, category visibility, and brush selection are
  reflected in the export, including the statistics drawn inside the chart.
- Sliders, checkboxes, and the actions menu are HTML controls and are not
  included in the image.

This works in the HTML files produced by `write_htmls` using the bundled
runtimes, without a CDN, server, Node.js, or extra gems. The export menu is
also enabled in IRuby output; notebook runtime loading follows the `vega`
gem's existing behavior.

```ruby
VGHelper.write_htmls(chart, "chart.html")
# Open chart.html, adjust the chart, then use the three-dot menu to save it.
```

To customize the export resolution or hide the menu, use the `vega` gem's
`embed_options` method. It returns a new chart:

```ruby
chart = chart.embed_options(
  actions: { export: true, source: false, compiled: false, editor: false },
  scaleFactor: { png: 3, svg: 1 }
)
# Or: chart = chart.embed_options(actions: false)
```

This feature saves images from the browser. It does not add a Ruby method
for writing image files directly.
